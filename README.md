# Formations – Troisième Hémisphère

Espaces formation en ligne (quiz, ateliers) publiés avec GitHub Pages.

- `acmb/` : ACMB Assurances – Découverte client et dossier client conforme
  - `index.html` : espace stagiaire (accueil)
  - `quiz.html` : quiz d'entrée / de sortie, écran formatrice (`quiz.html#animateur`)
  - `jeu-de-role.html`, `audit.html`, `engagements.html` : ateliers

Le suivi en direct du quiz passe par ntfy.sh (sans compte). Aucune donnée n'est stockée sur ce site : les saisies des ateliers restent dans le navigateur de chaque participant.
